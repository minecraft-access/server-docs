# About

Welcome to the official Minecraft Access Minecraft server. This is a server made by the Minecraft Access developers. Everything on this server is accessible and works with the Minecraft Access mod. While survival is the only available gamemode at the time of writing, we plan on expanding into minigames and other gamemodes in the future.

# How To Join

You can join with or without mods as long as your mods don't break any [rules]({{< relref "/rules" >}}). Also, the server is in online mode which means you have to own the game legitimately in order to join.

The server's IP is *server.mcaccess.org*. Here are instructions for how to join:
- Open Minecraft and select multiplayer
- Click proceed if the game warns you about multiplayer
- Click on add server
- Put anything as server name, and put *server.mcaccess.org* as the server address. Finally, click done.
- Now the server will be on your server list. Select it and press enter to join.

# Custom Features

This server contains some features that are not available in the vanilla game. Run the /help command in-game to see a list of them.
